Core Features

Everything Included

Five interconnected systems that create emergent gameplay — no two encounters are the same.

Custom Items

Two unique items with PersistentDataContainer identification. Echoing Core (glowing Echo Shard) and Riftblade (Netherite Sword with Sharpness V, Unbreaking III, Mending).

PDC Identified Vanilla-Proof Custom Recipe

Riftblade Combat

Passive Resonance Stacks build on consecutive hits (every 3rd = sonic boom + 6 armor-piercing damage). Active Phase Slash dashes 8 blocks, damages enemies in path, grants Speed II.

15s Cooldown Action Bar UI Armor-Piercing

Hollow Warden Boss

600 HP Warden with 3-phase fight: Sonic Shield (90% melee reduction, 3 nodes), Vibration Slam (≤50% HP, launches grounded players), Soul Tether (≤20% HP, heals while players stay close).

3 Phases BossBar 1-2 Core Drops

Altar Summoning

Player-driven ritual: Sculk Shrieker centered with 4 Chiseled Deepslate at cardinal directions (2 blocks out). Right-click with Soul Lantern → consumes item, lightning, broadcasts coords, spawns boss.

No Commands Server Broadcast PvP Hotspot

Competitive Tracking

Every 5 minutes, players holding a Riftblade (inventory or Ender Chest) ping their rough location to the entire server — world name + coordinates rounded to nearest 250 blocks.

5 Min Interval 250 Block Radius Ender Chest Check

Modern Architecture

Built for Paper 1.21.4+ (26.3+) with Java 21. Uses Adventure API for components, PDC for items, BukkitRunnables for timers. Clean modular structure — easy to extend or disable features.

How It Works

From gathering resources to server-wide boss hunts — the complete progression path.

1

Explore & Gather

Venture into the Deep Dark to collect Echo Shards and Breeze Rods. Hunt the Warden for more shards, or explore Trial Chambers for Breeze Rods.

Echo Shards
Breeze Rods
Warden Loot
2

Forge the Riftblade

Craft an Echoing Core (glowing Echo Shard), then combine with Netherite Sword, 2 Echo Shards, and 2 Breeze Rods in a custom shaped recipe to create the Riftblade.

1 Echoing Core
1 Netherite Sword
2 Echo Shards
2 Breeze Rods
3

Build an Altar or Spawn

Either use /hollowrift spawnboss (admin) or build the ritual: place a Sculk Shrieker, surround with 4 Chiseled Deepslate at N/S/E/W (2 blocks out), right-click with Soul Lantern.

Sculk Shrieker Center
4 Chiseled Deepslate
Soul Lantern
Cosmic Lightning
4

Fight the Hollow Warden

Coordinate with your team: break 3 shield nodes to drop the Sonic Shield (90% melee reduction), dodge Vibration Slams (every 12s below 50% HP), break Soul Tethers (below 20% HP) by moving 15+ blocks away.

Break 3 Nodes
Dodge Slams
Break Tethers
5

Claim & Compete

Boss drops 1–2 Echoing Cores. But every 5 minutes, your Riftblade pings your rough location to the entire server — world + coordinates rounded to 250 blocks. Defend your loot or hunt others.

1-2 Echoing Cores
5-min Ping
250 Block Radius

Installation

Requires Paper 1.21.4+ (build 26.3+) and Java 21. Works with all major permission plugins.

server/plugins/
# 1. Download the latest release
wget https://github.com/your-repo/HollowRift/releases/latest/download/HollowRift-1.0.0.jar
# 2. Place in plugins folder
mv HollowRift-1.0.0.jar /path/to/server/plugins/
# 3. Start/restart server
./start.sh
# 4. Verify in console
[HollowRift] HollowRift has been enabled!

For Server Owners

Why HollowRift?

Built for competitive SMPs that want meaningful progression, contested objectives, and a boss that demands coordination — not just gear checks.

True Competition

The 5-minute Riftblade ping creates natural conflict cycles. Players can't hide forever — every 5 minutes the server knows roughly where the blade is. This drives PvP, alliances, betrayals, and base defense.

Items That Matter

Echoing Core and Riftblade use PersistentDataContainer — they survive server updates, can't be duplicated by vanilla mechanics, and are identifiable by other plugins. The Riftblade isn't just a sword; it's a progression milestone.

A Boss That Fights Back

Three distinct phases force coordination: break shield nodes together, dodge slams as a group, break tethers by spreading out. No single player can cheese it — it requires communication and role assignment.

Modern, Stable Code

Paper 1.21.4+, Java 21, Adventure API, PDC, BukkitRunnables. No NMS, no reflection, no fragile version-dependent code. Shaded JAR with zero external runtime dependencies. Clean modular architecture.

Emergent Gameplay

No quests, no guided objectives — players create their own stories. Race to build the first altar. Form teams to break the shield. Betray allies for the core drop. Hunt the pinged Riftblade holder. The plugin provides tools; players write the narrative.

Extensible & Open

MIT licensed. Modular structure (items/, combat/, boss/, altar/, commands/) makes it easy to disable features, add custom drops, or hook into events. PDC keys are documented for integration with economy, leaderboard, or logging plugins.

Commands & Permissions

All admin commands with tab completion. Permissions default to OP but work with any permission plugin.

Command Description Permission Aliases
/hollowrift give core [player] Give an Echoing Core to yourself or target player hollowrift.give /hr give core
/hollowrift give blade [player] Give a Riftblade to yourself or target player hollowrift.give /hr give blade
/hollowrift spawnboss [player] Spawn The Hollow Warden at player's location (or yours) hollowrift.spawnboss /hr spawnboss

Permission Defaults

hollowrift.admin

All admin commands (give, spawnboss)

hollowrift.give

Give custom items only

hollowrift.spawnboss

Spawn boss only
